### 2024/10/14 14:58 — [人名5]

在RTC mode觸發任何PMU intterrupt會使系統增加約10mA耗電。

Root cause : PWR key 按壓完後釋會進入到 RTC mode ; 此問題乃因為放系統進入RTC mode時，SW 有些事情沒有做完 (尚未關閉 intterrupt上拉電源) 導致持續漏電 

Patch 主要針對 Power off or Power on sequence 分別加了一些判斷
 * Power off 過程 : 在還沒有進 RTC mode 前就先 REGEN key rising & falling interrupt 關閉
 * Power on 過程 : 開機 PMU init 過程, 利用 一個 PWR key press timer 保護, 一定要確保時間要 > 這設定值才給開機  ; 避免按得不夠久, 遇到此問題

</div>
