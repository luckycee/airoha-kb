### 2025/10/29 16:45 — [人名2]

# 法律和商业保障

* 所有 ODM/EMS/合作伙伴协议都必须包含禁止逆向工程、固件提取和密钥披露的强有力的 NDA 和知识产权条款。
* DSP/AI 算法和固件架构的版权登记和可选专利。
* 代码托管和开发库的安全访问管理。

# 安全启动和代码签名

* 在所有生产单元上启用安全启动。只有签名固件才能执行。
* 使用 Harmonix 私钥签署引导加载器、应用程序和 DSP 二进制文件。
* 将公共密钥哈希值编入片上 OTP/保险丝。
* 启用防回滚保护，防止降级攻击。

# 固件保密和加密

* 在静态和传输过程中使用加密固件映像。
* 密钥按产品线衍生并定期轮换。
* 使用硬件密钥梯或 OTP 存储器在设备上解密。

# 调试和接口锁定

* 在生产中永久禁用 JTAG、UART 和 SWD 端口。
* 删除或加密限制出厂调试指令（RACE/工程模式）。
* 对任何重新激活执行签名挑战验证。

# OTA 和更新完整性

* 所有 DFU/OTA 更新在安装前都必须在设备上签名和验证。
* 执行基于 Nonce 的版本控制和防重播。
* OTA 机制必须在验证失败时关闭。

# 人工智能模型和算法保护

* 尽可能将核心 DSP/AI 资产放在设备外。
* 需要在设备上存储时，进行混淆和加密。
* 使用模型水印追踪未经授权的副本。

# 运行时和防篡改控制

* 对固件完整性实施校验和/自检验证。
* 增加看门狗、时序一致性和调试检测机制。
* 在出现违规时故障安全关机或限制模式运行。

# 工厂安全与密钥管理

* 工厂只接收公钥和短期签名令牌。
* 金色图像和哈希值仅由 Harmonix 安全存储。
* 生产后随机抽样检查，以确认保险丝和密钥状态。

# 供应链与漏洞响应

* 为所有构建维护 SBOM，包括 ABT SDK 依赖项。
* 订阅 ABT 和蓝牙技术联盟公告。
* 实施 30 天关键漏洞补丁 SLA。

# ODM 合规交付
每个 ODM/EMS 合作伙伴必须在量产前提供以下信息：

* 安全启动、熔断状态和密钥配置的屏幕截图证据。
* 确认已禁用调试接口。
* 固件签名验证报告。
* 配对、OTA 和维护渠道的安全测试结果。
* 每次固件发布时的持续合规性认证。
