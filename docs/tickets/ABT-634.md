這是正常的，system sleep時收到第一個cmd僅能喚醒系統，data會丟失

system active後才能正常處理cmd

讓Device不進sleep mode

*AT+SM=LOCK,1,SLP*

對應code function 

hal_sleep_manager_lock_sleep(sleep_manager_handle)

 

 

AT+SM=LOCK,0,SLP    (用sleep manager handle unlock系统)

對應code function 

hal_sleep_manager_unlock_sleep(sleep_manager_handle);
