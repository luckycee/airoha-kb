> 📅 2025/10/28 15:49　🔗 [原始工单链接](https://eservice.airoha.com.tw/servicedesk/customer/portal/1038/MIUIX1565-624)

## 问题描述

Hi [人名5]，

把 PMIC_SHORT_TOUCH_PWR_ON_PROTECTION 改为 1之后，短按之后就不会开机了，需要满足长按设置的时候才会开机。平时短按不到开机时间的话会进入到RTC mode。

客户触发了一个比较奇怪的bug。power key 触发了短按，然后在几乎相同的时间内把耳机入仓进行charge，此时发现只有 power key 触发之后进入RTC的log，没有charge的log，这导致了耳机无法充电、无法显示充电灯。请看看有什么方法解。触发的概率有2-5%的样子，客户使用的外挂touch接power key。

附件是demo 编译出来的FW，把PMIC_SHORT_TOUCH_PWR_ON_PROTECTION 改为 1 。EVK 上也是很容易发现问题。
