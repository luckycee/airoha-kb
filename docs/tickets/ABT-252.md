### 2023/10/20 19:35 — [人名1]

Hi , @[邮箱已隐藏]

  dongle 是 RX , 在它主动断开之后, 不会继续回连TX,  若需要回连,则应该主动连接 TX . 比如可以使用 AT+LEULL=CONN,SIRK

  其他指令可以参考: 

App_ull_idle_activity.c (mcu\project\ab156x\apps\bt_audio_common\src\apps\app_ull): .command_head = "AT+LEULL", /**< AT command string. */

 

 MIC 是 TX , 在它主动断开之后,  不会继续广播. 若需要回连, 则应该主动开启广播. 比如可以使用 AT+LEULL=ADV,start

 其他指令可以参考: 

Bt_app_common_at_cmd.c (mcu\project\ab156x\apps\dongle_ref_design\src\bt_app_utility): .command_head = "AT+LEULL", /**< AT command string. */

 

谢谢
