# MIUIX1565-400 dongle 项目USB跟line in连接同一个电脑有低噪

> 📅 2024/06/12 19:47　🔗 [原始工单链接](https://eservice.airoha.com.tw/servicedesk/customer/portal/1038/MIUIX1565-400)

## 问题描述

Hi 李工，

客户现在遇到一个硬件问题，是由于Dongle的3.5输入接入到1565D的模拟输入口，此时如果使用同一个PC给Dongle充电，并通过3.5输出音频给到Line in端，能够比较明显听到底噪。

客户认为这个电流声是因为 3.5mm信号线上有接地线做信号回路，但是低频的3.5mm模拟音频信号也会从USB电缆的地线回流到电脑，目前通过分离模拟地和充电地去解决这个问题（他们已经测试过通过滤波器件但并没有效果），但是解决了这个问题呢又有一个新问题是没有办法解决插入检测的问题，请帮忙看下是否还有更好的方案。
