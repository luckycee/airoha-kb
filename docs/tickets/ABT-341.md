### 2024/02/27 17:40 — [人名17]

HI @[邮箱已隐藏]

055A0300D50C00 get bd address，这是agent的，并不是local的address。

local bd address存放在nvkey：0x183E

使用race cmd read nv：055A0600000A3E180600就可以了。读出来的值是低位在前高位在后，自己要反一下。

使用race cmd rwrite nv：055A0A00010A3E18XXXXXXXXXXXX。写进去的BD address也需要低位在前，高位在后。

写完后请把183D reset或者重新air pairing。
