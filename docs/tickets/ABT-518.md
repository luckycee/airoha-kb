### 2025/03/11 14:46 — [人名2]

I found the 2 issues are linked to the same setting. 

Noise and distortion are audible when playing audio at low volume level
This can be replicated by using AP test software inputting a sine tone at low level (for example -80dBFS) and adjusting the dither settings (on/off/bits)
Dither: [https://www.ap.com/category/news/dither|https://www.ap.com/category/news/dither]
This is an issue for customers using:
Music production software, for example: Ableton Live, Adobe Audition
DJ software, for example: Traktor, Pioneer Rekordbox
Issue is not present on audio interfaces, for example Focusrite 2i2
