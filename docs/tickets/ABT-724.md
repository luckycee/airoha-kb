Hi heng zhang (qq)



前提条件：

* headset 开启了multi mode，和 a2dp standby
* headset 同事连接了SP 和dongle
* 客户有一个key 动作来切换SP mode或dongle mode

期望：

* 在SP mode下，播放SP的音乐或者视频有声音。dongle不会有声音。
* 切换到dongle mode下，播放dongle 的音乐或者视频有声音。SP不会有生意。
* 

SP mode 、dongle mode，在客户那边就是一个bool 的全局变量，用来区分两个mode。
