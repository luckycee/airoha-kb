### 2024/12/19 11:25 — [人名80]

Hi @[邮箱已隐藏] 

我們有support flash tool disable 

可以透過efuse 開啟這個功能

但因為efuse是 one-time programmable

一但開啟這個功能後, 就再也不能關閉

設定了之後 flash tool對flash的所有操作都會不能用

包括 flash download / flash readback 就都不行

efuse read/write也都不行了 (因為efuse是透過CODA tool去read/write)

ＲＭＡ分析也不能做

通常需要放在產線最後一站 才去enable

 

 

还有一种叫做: Tool Authentication，通过otp烧入一个key，而flash tool必须在有正确key才能进行操作

這個功能一樣需要燒某些efuse，放在產線最後一站

燒了efuse以後,  flash tool都需要先送一個"證書 certificate" 給 bootrom,

bootrom 確認"證書"是正確的, 才開放flash tool download DA

*{color:#d04437}但這會有一個麻煩的地方{color}*

*{color:#d04437}Airoah有提供"certificate generator"{color}*

*{color:#d04437}這個證書會結合 device的UID{color}*

*{color:#d04437}所以每顆IC, 都需要產生自己的證書{color}*

也就是說, 假設今天有一顆RMA IC, 或是 需要燒load的IC

user必須先得知這顆IC的 UID （我們有race cmd可以get UID）

然後把UID提供給客戶,   客戶再產生證書給這個user

user才能夠對這顆IC 使用flash tool

{color:#d04437}因為針對每一顆IC, 都要產生證書，所以你们那邊需要建立一個 "產生證書" 的單位，ABT會提供 "證書產生器" 給你们使用{color}
