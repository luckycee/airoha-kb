要用race_dsprt_peq_realtime_data 这个api哈，uint8_t *p_coef, uint32_t coef_size 就是data和长度

uint32_t race_dsprt_peq_realtime_data(uint8_t phase_id, uint8_t setting_mode, uint32_t target_bt_clk, uint8_t *p_coef, uint32_t coef_size, am_feature_type_t audio_path_id)

phase id 对pre peq 生效这里填0

setting mode 代表是要aws 同步的话 就 1，headset 就 0

target_bt_clk  表示同步的 bt clk

audio_path_id 就是 什么场景，比如A2DP 就是 AM_A2DP_PEQ
