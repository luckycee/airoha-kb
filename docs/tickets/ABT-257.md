一个是dongle端的gain table 1, dongle端到earbuds的声音，会经过这里调整音量

想要不修改dongle端的gain table，那就试试在earbuds端BLE Audio 场景不用 gain table 2。 然后调整 gain table 2向 gain table 1靠拢。
