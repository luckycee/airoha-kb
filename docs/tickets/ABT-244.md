### 2023/09/11 15:37 — [人名5]

Hi @[邮箱已隐藏]，

如电话沟通，你们OTA 会 OTA 0x1900这条nvkey。这样会导致多台earbuds 的 SIRK 跟 set size 一样。dongle 连接这3台 earbuds后bonded list 就会有一样的3台耳机，這三台裝置...set size都是1，group 皆為0 ,所以三台的sirk 設置都一樣, set size都是 1。

麻烦问清楚客户为什么要升级这条nvkey，正常是不能这样OTA的。

要确保earbuds 左右耳sirk要設置一樣

但是不同台的earbuds sirk 要不同

ex:
Earbuds_A 左耳, set size = 2, 使用 SIRK_A, 
Earbuds_A 右耳, set size = 2, 使用 SIRK_A
 
Earbuds_B 左耳, set size = 2, 使用 SIRK_B
Earbuds_B 右耳, set size = 2, 使用 SIRK_B
 
Headset_C, set size = 1, 使用 SIRK_C

SIRK_A, SIRK_B 跟 SIRK_C 必須不同 (且須為非全0內容)
