### 2023/07/26 18:23 — [人名33]

Hi Sir,

 

耳機端如果有 TWS 狀態變化會發一個 {color:#14892c}05 5D 的 notify{color} 給 APP SDK

APP SDK 會再 callback {color:#59afe1}onChanged TWS_STATUS{color} 的 message 給 APP UI

{color:#d04437}APP UI 收到 TWS_STATUS 的狀態通知後, 如果要在app上看到彈窗的話, 需要自行實現跳彈窗的動作{color}
