## 问题描述

Hi [人名5]，

项目评估时提出I2S 无输入也要输出0 data （[ABT-67](ABT-67.md) ），后来项目开始做后提出要求实现（[ABT-127](ABT-127.md)），你提供了几次patch 都无法达到目的，他们就不需要这个功能了现在遇到了pop声问题（[ABT-189](ABT-189.md)），通过ASRC解决了，但是未能完全解决，“由于蓝牙的I2S信号是有声音的时候才有，没声音的时候没有I2S信号，ASRC有数据输入缓冲，当上一轮信号推入停止，缓冲区有残留数据，下一轮数据推入会和缓冲的残留数据连接，由于两轮数据没有连接关联性，新一轮数据推入时会产生很大的噼啪声，这是不能接受的。”，他们认为 I2S做主开机就连续输出直至关机才停的，或者I2S做从的才能解决。

所以回到了最开始的问题。
