# ABT-292 AB1565 off mode 下开机慢，导致BT on pattern 无法收取

> 📅 2023/11/13 11:33　🔗 [原始工单链接](https://eservice.airoha.com.tw/servicedesk/customer/portal/1038/MIUIX1565-292)

## 问题描述

HI [人名5]，

1. demo code在 power off 之后会进入RTC mode；

2. RTC mode 下收取 BT on patter 没有问题

3. RTC mode 下功耗为 19uA左右；

因为功耗问题，[客户A]那边要求修改 power off 之后 进入到OFF mode（相关[ABT-162](ABT-162/)），能够达到要求的功耗了。但是客户发现如果耳机充满电的状态（就是耳机进入了OFF mode），开盖后比较快的速度拿出来无法开机（客户有要求直接掉5V不能开机，只能收码开机）。

通过专区VBUS_UART的信号发现，在OFF mode下，耳机不识别BT on pattern ，等pattern 过了才能够识别，如果从5V上来后计算，大约需要1.8s才能识别pattern。在RTC mode 下不会有此问题，第一个BT on pattern 就识别了。

OFF mode 下是否能够加快开机流程？

Hi @[邮箱已隐藏]，

這個參數是為了 BootROM 裡的 USB download 的等待時間，只要從 OFF mode 開機起來時 VBUS 有 5V，BootROM 就會進入這個 flow，改成 0 ，就是不會有 USB download。

如果客戶產品沒有出 USB PIN，那這裡改0，不會造成影響。
