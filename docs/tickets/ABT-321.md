Hi @[邮箱已隐藏]

可以幫忙確認客戶是要用手機 App 建立 SPP 連線還是 LEA 連線嗎?

建立 SPP 連線: 
如果手機跟耳機已經建立 LEA 連線，這時候會取決於手機的行為是否會斷開 EDR 連線
若 EDR 連線斷開，則手機 App 去建立 SPP 連線就會失敗
若 EDR 保持連線，則手機 App 去建立 SPP 連線就會是正常的

建立 LEA 連線: 
156x Android SDK v3.5 還沒有支援建立 LEA 連線，確實要升級到 Android SDK v3.9
但客戶可以先用 v3.9 的 sample code 進行測試，看行為是否都符合他的預期
