## 问题描述

Hi [人名5]，

headset 的 source input ：SP、line in (ADC0/ADC1, I2S_master_in )、USB audio、dongle

headset 的 output ：analog speaker output、I2S master/slave out

现在有个项目需要新增一个SPI 作为 source input 和 output 。有个UWB 芯片只能接收SPI，蓝牙需要把 output 打包成SPI 能够传送的data，经过了UWB的TX和RX 之后，再给回蓝牙作为蓝牙的 input ，最后经过speaker 播放出来。请帮忙看看我们AB1577M能不能做？

蓝牙SPI的要求：

做 slave

clock source 支持到 31MHz

SNR 好于 -110dB
