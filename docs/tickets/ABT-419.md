Hi @[邮箱已隐藏] ，

發送Race CMD的功能. 只有SDK API. 使用說明如下.

APP UI沒有此功能.

 

You can use sendCustomCommand API to send RACE commands using the Airoha SDK
 - returns: if device have result return, library will delegate AirohaConnectionListener::onDataReceived(rawData: Data)

AirohaSdkMgr.Inst.getAirohaConnector().sendCustomCommand(data: data)

 

ex:

let data = Data([0x05, 0x5A, 0x03, 0x00, 0xD6, 0x0C, 0x00]) // get agent battery

AirohaSdkMgr.Inst.getAirohaConnector().sendCustomCommand(data: data)

 

You can recevie the result "05 5B 03 00 D6 0C 00" and "05 5D 05 00 D6 0C 00 00 64" from AirohaConnectionListener::onDataReceived delegate.
