    HI @[邮箱已隐藏]

    bt_customer_config_allow_play API 会在两个设备抢占 audio 资源时被调用，可以通过返回以下值来表示允许、不允许此次抢占或使用 SDK 的默认行为：

    [图片: image-2022-12-06-10-37-41-725.png]

    不允许抢播，需在 bt_customer_config_allow_play 中返回 BT_SINK_SRV_ALLOW_RESULT_DISALLOW，随后 bt_sink_srv_get_config 将会被调用，函数的第一个参数一般为 BT_SINK_SRV_GET_REJECT_CONFIG

    允许抢播，需在 bt_customer_config_allow_play 中返回 BT_SINK_SRV_ALLOW_RESULT_ALLOW，随后 bt_sink_srv_get_config 将会被调用，函数的第一个参数一般为 BT_SINK_SRV_GET_SUSPEND_CONFIG

    使用默认设置，需在 bt_customer_config_allow_play 中返回 BT_SINK_SRV_ALLOW_RESULT_BYPASS

    bt_sink_srv_get_config 将在 SP2 释放资源后被调用，函数的第一个参数一般为：BT_SINK_SRV_GET_RESUME_CONFIG

    麻烦参照图片修改：默认code里面没有bt_sink_srv_get_config，只做了申明，没有定义，麻烦自己写一个，你可以copy default_bt_sink_srv_get_config ，把名称改为bt_sink_srv_get_config，然后将BT_SINK_SRV_GET_SUSPEND_CONFIG部分替换原有的部分，如图红框位置：

    [图片: image-2022-12-06-10-15-23-681.png]

    [图片: image-2022-12-06-10-24-41-003.png]
